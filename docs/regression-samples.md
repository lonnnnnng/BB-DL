本清单用于持续验证 `BB-DL` 与原版 BBDown 的线上行为差异。样本分为“已验证”和“候选样本”：候选样本来自原版 README、原版源码注释或当前测试线索，只有实际跑过命令并记录结果后，才能改成已验证。

## 回归原则

- 优先跑 `info` / `--only-show-info` / `--cover-only` / `--sub-only` 等低副作用命令，确认解析链路后再跑完整下载。
- 需要登录、会员、区域代理或 BiliPlus 的样本必须标注账号状态、token/cookie 来源类型和执行日期，不记录任何真实密钥。
- 每条样本至少记录：命令、是否登录、期望关键输出、实际结果、失败错误。
- 下载类样本统一使用临时 `--work-dir`，避免污染日常下载目录。
